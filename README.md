# Pancancer-CM-Epi-Workflow
Code for “Coupled epithelial and microenvironmental states define spatial ecosystems in clear cell renal cell carcinoma,” with reusable agent skills for single-cell preprocessing, cell-subtype annotation, cellular-module discovery, Epi–CM association testing, and spatial mapping, plus cross-cancer applications in Pancancers(CRC, GC and PDAC))
