About these annotations

The final atlas combines 61 tumor samples and 22 normal-like samples. Normal-like is the harmonized normal/non-tumor kidney comparison group.

Each point represents one cell. The primary cross-cellular module (CM) label is a display summary inherited from the non-epithelial cell subtype, not an independently inferred module assignment for each cell. A subtype may contribute to multiple modules. This viewer shows coordinates and annotations only, not gene expression.
